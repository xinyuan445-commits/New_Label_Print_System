# 使用指南

## 登录

使用管理员提供的账号和密码登录。首次登录若提示修改密码，请先完成修改。

## 设计模板

进入“模板管理”，新建模板并选择标签尺寸。在编辑器中添加文字、条码或图片；可在文字和条码内容中使用 `{{变量名}}`。保存后，模板可用于单据预览。

单据打印页使用的变量包括 `{{单据编码}}`、`{{行号}}`、`{{物料编码}}`、`{{物料名称}}`、`{{批号}}`、`{{数量}}`、`{{单位}}`、`{{sn}}` 和 `{{条码}}`。

## 查询单据与预览

进入“单据打印”，选择单据类型，按单据号或日期查询。点击单据查看明细，填写数量和包装方式，选择模板后预览。普通单据未勾选明细时按全部可打印明细处理；从首页待打印进入时只处理可确定的剩余明细。点击“设置常用单据”，可选择最多八种常用单据。

预览不写入 U8。998 测试账套支持打印和登记；008 正式账套只读查询。首页待打印不受个人常用单据限制，部分打印会继续显示，待核对项目需人工确认。

## 存货与补打

“存货打印”按仓库、货位、料号或批号查询，必须勾选库存。点击库存标题旁的已选项入口，核对选择、数量和包装方式后打印。

“标签补打”输入原流水号查询，选择模板和打印机后补打。补打保留原条码和 SN，不新增首次打印记录；暂不统计补打次数。

## 打印与生成记录

选择“浏览器打印”无需安装：在 PDF 工具栏选择本机打印机，核对输出后勾选确认并完成。取消窗口不会登记。助手模式可直接选择已安装的本机打印机，Microsoft Print to PDF 按单号、行号和 SN 保存。

出现待确认任务时先核对出纸情况，使用原任务确认或登记重试，不要直接再打一批。生成记录中点击行可预览，下载按单号命名。

## 打印机

“打印机管理”可安装可选打印助手，读取当前员工电脑已安装的打印机，并设置默认项和是否显示。无助手时使用浏览器打印。
