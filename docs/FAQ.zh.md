# 常见问题

### 为什么查不到单据？

先检查数据库连接、单据类型、日期和单号。998 用于测试打印；008 只读查询。未配置或查询失败时页面会提示。

### 为什么打印机列表为空？

自动列出队列需要在当前员工电脑安装并启动打印助手，从助手创建的桌面入口进入。无助手时选择“浏览器打印”，在系统打印对话框中选择本机打印机。

### 预览会生成正式追溯码吗？

不会。预览只检查排版，使用临时标记，不写追溯表，也不发送打印任务。

### 重启后模板会丢失吗？

正常重启不会。本机模板在 `.local-data/pilot.db`，图片和打印快照也在 `.local-data`。换电脑需要单独迁移数据；从 GitHub 下载源码不会带回原来的模板和账号。

### 为什么某些单据显示待核对？

旧标签记录缺少明细身份或存在冲突，无法确定对应哪一行。需要人工核对，不能自动当作未打印再打。

### 打印后提示登记失败怎么办？

先核对打印机出纸，用原任务恢复确认或重试登记，不要直接重新打印。补打使用原 SN，暂不统计打印次数。
